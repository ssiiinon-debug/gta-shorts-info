Shorts Pipeline

Shorts Pipeline is a personal automation tool that schedules and publishes YouTube Shorts videos to the owner's own YouTube channels. It uses the YouTube Data API to upload videos that the account owner provides, and Google Drive API to transfer files between the owner's Google Drive folders.

The app is operated by an individual content creator for personal channel management. It does not offer public accounts, does not serve third parties, and does not collect user data.
